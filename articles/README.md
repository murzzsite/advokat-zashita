# Статьи блога

Один файл = одна статья: `articles/<slug>.md`.

Жизненный цикл поля `status`:

| status | что происходит |
|---|---|
| `draft` | черновик. Готова к публикации: клиент видит её в кабинете, страница-предпросмотр закрыта от индексации |
| `approved` | клиент нажал «Опубликовать». Сборщик сам назначает дату выхода (по умолчанию раз в 7 дней) |
| `published` | статья на сайте, в sitemap и RSS. Ставится автоматически, когда наступила дата |

Руками менять `date`, `notified` и `status: published` не нужно. Для `draft` достаточно положить файл сюда и сделать `git push`.

## Контент-план на 4 недели

Все статьи создаются со `status: draft`. Клиент публикует их сам из кабинета, выход раз в 7 дней.

| Неделя | Тема (slug) | Основной ключ | Интент | Услуга / CTA |
|---|---|---|---|---|
| 1 | Что делать, если близкого человека задержали: первые 48 часов (`chto-delat-pri-zaderzhanii-blizkogo`) | что делать при задержании | информационный | Уголовная защита, ссылка на «Первые 48 часов», заявка /#contact |
| 2 | Как выбрать адвоката по уголовному делу (`kak-vybrat-advokata-po-ugolovnomu-delu`) | как выбрать адвоката по уголовному делу | коммерческий | Соглашение и оценка перспектив, заявка /#contact |
| 3 | Сообщение о преступлении в КУСП: как потерпевшему добиться проверки (статьи 144–145 УПК РФ) | заявление о преступлении КУСП | как сделать | Представительство потерпевших, /#practice |
| 4 | Когда компании нужен адвокат по арбитражному спору: договорные споры, взыскание, обеспечение иска | адвокат по арбитражным спорам | коммерческий | Арбитраж для компаний, /#practice, /#contact |

Правила для недель 3 и 4: только факты с сайта (практика, статьи УПК с главной, города и суды), без цифр и цен (гонорар индивидуально), без обещаний результата, дисклеймер включён в `blog.config.json`.
