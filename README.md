# advokat-zashita

Лендинг адвоката (уголовные и гражданские дела, Москва / Санкт-Петербург / Великий Новгород).
Чистый HTML/CSS/JS. Заявки: Cloudflare Worker -> Telegram (ref X4EAVX633J).

Заменить после уточнения: имя адвоката, статус (коллегия, реестровый номер), телефон/Telegram, реквизиты в privacy.html,
подтвердить формулировки в блоках «Как устроена работа», «Практика», FAQ.
